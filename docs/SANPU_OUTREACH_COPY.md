### タイトル

### 本文

「プログラム」を日本語で言うなら、「算譜」はどうだろう。

そう考えて調べ始めたところ、これは新しい造語ではありませんでした。辞書には1957年の用例があり、情報処理分野の文献や1991年の専門書にも登場します。現在も神奈川大学プログラミング科学研究所では、「算譜意味論」「算譜検証論」という言葉が使われています。

つまり「算譜」は、誰も使ったことのない新語ではなく、いったん使われながら一般には定着しなかった言葉です。

では、現代の文章で本当に使えるのでしょうか。

令和新漢語では、一語だけを眺めるのではなく、次の五つを一つの語族として試します。

- プログラム → 算譜（さんぷ）
- プログラミング → 作譜（さくふ）
- プログラマー → 算譜師（さんぷし）
- プログラミング言語 → 算譜言語（さんぷげんご）
- テストプログラム → 試譜（しふ）

例えば、

「プログラマーは、プログラミング言語を使ってプログラムを作り、テストプログラムで動作を確かめる」

は、

「算譜師は、算譜言語を使って算譜を作譜し、試譜で動作を確かめる」

となります。

短く、関連語をまとめて作りやすいのは長所です。一方で、「作譜」は音楽用語と衝突し、「算譜師」は職業人に意味を狭めるかもしれません。読みも、説明なしでは伝わりにくいでしょう。

だから、今すぐ正解と決めるのではなく、実際の文で試します。

初見で意味を推測できるか。文章や会話に繰り返し入れられるか。関連語が同じ体系として自然に読めるか。「使える」だけでなく、「ここでは使いにくい」という具体例も大切な材料です。

### 本文

「プログラム」の日本語案として、**算譜（さんぷ）**という語を検討しています。ただし、これは新造語ではありません。辞書には1957年の用例があり、専門書や研究にも使用例が残っています。

この記事では、単語一つの置換ではなく、周辺語へ自然に展開できるかを試します。

## 試す5語

| 原語 | 日本語案 | 読み | 想定する意味 |
|---|---|---|---|
| program | 算譜 | さんぷ | 計算機に実行させる処理の記述 |
| programming | 作譜 | さくふ | 算譜を設計・記述・試験・修正する活動 |
| programmer | 算譜師 | さんぷし | 算譜の作成を主な活動とする人 |
| programming language | 算譜言語 | さんぷげんご | 算譜を記述するための人工言語 |
| test program | 試譜 | しふ | 動作を確かめるために作る算譜 |

## 一文を置き換える

置換前:

> プログラマーは、プログラミング言語を使ってプログラムを作り、テストプログラムで動作を確かめる。

置換後:

> 算譜師は、算譜言語を使って算譜を作譜し、試譜で動作を確かめる。

語の関係は短くまとまります。一方、読みや意味が共有されていない状態では、置換後の文の方が理解に時間がかかります。特に「作譜」は音楽用語として定着しており、文脈なしでは衝突します。

## 評価したいこと

1. 漢字から意味の方向を推測できるか
2. 派生語が同じ体系として自然に読めるか
3. 技術文書、授業、会話で繰り返し使えるか
4. 既存語との衝突が、文脈で解消できる範囲か
5. 英語の原語より概念理解を助けるか

語の短さだけでは、実用的な訳語とは言えません。「この文脈では使える」「ここでは誤解される」という境界を集める必要があります。

## 現時点の見立て

基幹語の「算譜」は、使用史があり、書く・直す・実行するといった日本語の動詞にも接続できます。そのため試用する価値があります。

一方、「作譜」「算譜師」「試譜」は、音楽との衝突、職能範囲の限定、初見での読みづらさが目立ちます。語族全体を一括採用するのではなく、一語ずつ使える範囲を確かめるべきだと考えています。

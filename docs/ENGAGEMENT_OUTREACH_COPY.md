#令和新漢語 #日本語 #言い換え

## note

### タイトル

「エンゲージメント」は、なぜ一語で訳せないのか

### 本文

「社員のエンゲージメントを高める」

この文を日本語にするなら、「社員の働きがいを高める」が自然でしょうか。それとも「組織への愛着を高める」でしょうか。

同じ「エンゲージメント」でも、使われる場所によって指しているものが違います。

SNSの投稿なら、いいね、返信、共有などの反応を数えているかもしれません。Webサイトなら、一定時間の閲覧や重要な行動を測っているかもしれません。職場なら、社員が仕事にどれだけ活力や熱意を感じているかを尋ねているかもしれません。

原語が同じでも、測るものは同じではありません。

そこで、令和新漢語では次のように言い分けます。

- 投稿のエンゲージメント → 反応度
- 利用者のエンゲージメント → 関与度
- 社員のエンゲージメント → 働きがい
- 組織へのエンゲージメント → 組織への愛着

例えば、

「投稿のエンゲージメントを分析する」

を、

「投稿への反応度を分析する」

とすれば、何を見ようとしているのかが具体的になります。

一方、

「社員のエンゲージメントを高める」

を、

「社員の働きがいを高める」

とすれば、単に数値を上げるのではなく、仕事から活力を得られる状態をつくるという目的が見えます。

ただし、「働きがい」も完全な訳ではありません。

厚生労働省は、ワーク・エンゲイジメントを「活力・熱意・没頭」がそろった心理状態として整理しています。「働きがい」は一般向けには分かりやすい一方、待遇、職場環境、仕事の意義など、より広い意味にも読めます。

「組織への愛着」も、仕事への関与や熱意のすべてを含むわけではありません。

だから、一つの正解を決めるより先に、次の三点を確かめる必要があります。

1. 何を数え、何を観察しているのか
2. 誰と何の関係を指しているのか
3. その後、何を変えたいのか

カタカナを消すことが目的ではありません。カタカナの中に隠れた違いを、日本語で見えるようにすることが目的です。

今回の記事では、分野ごとの定義と四つの言い分けを、使用例とともに整理しました。

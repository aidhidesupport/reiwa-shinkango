## X

「エンゲージメントを高める」と、よく言います。

でも、投稿、利用、職務、組織では、指しているものが違います。

そこで、四つの漢語に分けました。

- 反応度
- 関与度
- 熱意度
- 愛着度

令和新漢語の提案語は、必ず漢語で造る。これは変えない原則です。

#令和新漢語 #日本語 #言い換え

## note

### タイトル

「エンゲージメントを高める」って、結局どういうこと？

### 本文

「社員のエンゲージメントを高めたい」

仕事の場で、よく耳にする言い方です。でも、実際には何をすればよいのでしょう。

社員の熱意度を高めることなのか。組織への愛着度を高めることなのか。この一文だけでは、目指しているものがよく分かりません。

「エンゲージメント」は、使われる場所によって中身が変わります。

SNSの投稿なら、いいねやコメント、共有の数を指すことがあります。Webサイトなら、どのくらい長く、繰り返し使われているかを見ることがあります。職場なら、仕事への熱意や組織への愛着について話していることもあります。

令和新漢語では、ここで長い説明句へ戻しません。意味を分けたうえで、繰り返し使える漢語を造ります。

- 投稿に現れた反応の強さは「反応度」
- サービスとの関わりの深さは「関与度」
- 仕事に向ける活力、熱意、没頭は「熱意度」
- 所属する組織への心理的な結びつきは「愛着度」

例えば、

「投稿のエンゲージメントを分析する」

は、

「投稿への反応度を分析する」

と書けます。

「社員のエンゲージメントを高める」

なら、

「社員の熱意度を高める」

とすれば、組織への愛着ではなく、仕事そのものへの熱意を扱うことが明確になります。

もちろん、いつでも簡単に言い換えられるわけではありません。

厚生労働省は「ワーク・エンゲイジメント」を、仕事に対する活力、熱意、没頭がそろった状態だと説明しています。「熱意度」は、この三要素を一語で完全に言い尽くす確定訳ではなく、文章の中で試す新漢語案です。

熱意度と愛着度も同じではありません。両方を確かめたいなら、一語へまとめず、二つに分けて測る方がよいでしょう。

「エンゲージメント」と書きたくなったときは、次の三つを考えてみます。

1. 指標対象は何か
2. 関係主体は誰か
3. 改善目標は何か

カタカナ語をなくすことだけが目的ではありません。現代の概念を、日本語の中で繰り返し使える漢語として育てることが目的です。

記事では、反応度、関与度、熱意度、愛着度という四つの三字漢語案を、使用例とともに検討しました。

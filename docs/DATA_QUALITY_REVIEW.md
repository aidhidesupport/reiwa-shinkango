# 初期データ品質レビュー

最終更新: 2026-07-26

## 目的

本番公開前の初期データについて、日本語案の比較可能性、使用例の成立、重複、
分類の偏りを確認する。機械的に判定できる不整合は `npm run audit:data` で継続監視し、
表現の自然さはこの文書で編集レビューの対象を管理する。

## 対象と方法

- 対象: `prisma/seed.ts` から空のSQLiteデータベースへ投入した初期データ
- 規模: 120項目、124の使われ方、245日本語案、245使用例
- 機械監査:
  - 各項目に2案以上あるか
  - 同じ使われ方の中に同一表記の日本語案がないか
  - 日本語案と元の言葉が同一でないか
  - 合う場面、理由、使用例が欠けていないか
  - 元文と言い換え文が同一でないか
  - 正規化後に同一となる項目がないか
- 編集レビュー:
  - 共通テンプレート例文の自然さ
  - 複数項目に現れる同じ日本語案の意味の重なり
  - 説明なしでは意味を推測しにくい候補

監査手順:

```bash
npm run db:reset
npm run audit:data
```

既存データを消したくない環境では、空の検証用データベースを別に用意し、
`DATABASE_URL` をそのデータベースへ向けて実行する。

|---|---:|---|
| 2案以上ある項目 | 120 / 120 | 合格 |

| 使用例がある日本語案 | 245 / 245 | 合格 |
| 同じ使われ方の中の重複案 | 0件 | 合格 |

「クラウド」の第1案が「クラウド」のままで、例文も変化していなかった1件は、
第1案を「外部計算基盤」に修正した。

## 編集レビューの結果

### 1. 共通テンプレート例文

初回監査では114項目、228使用例が次の共通テンプレートを使っていた。

- `○○を確認する。` → `日本語案を確認する。`: 初回114件、現在0件
- `○○を見直す。` → `日本語案を見直す。`: 初回114件、現在0件

文法的に成立する例もあるが、実際の利用場面を示せず、候補によっては不自然になる。
たとえば「アイスブレイクを確認する」「インフルエンサーを見直す」は、
その言葉が現実に使われる文脈を十分に表していない。

判定: データ構造上の不整合ではないが、公開品質としては要改善。

対応方針:

1. 分野ごとに20項目前後の単位で編集レビューする。
2. 元文は実際に横文字が使われる文、言い換え文は同じ意味と情報量を保つ文にする。
3. 1案目と2案目で、合う場面の違いが分かる例を優先する。
4. 更新後に `npm run audit:data` と詳細ページの表示確認を行う。

### 2. 複数項目に現れる同じ日本語案

初回監査では、次の3案が異なる横文字項目に重複していた。

| 日本語案 | 項目 | 対応 |
|---|---|---|
| 対応項目 | タスク / アクションアイテム | タスク側を「作業項目」へ変更 |
| 接点 | チャネル / タッチポイント | チャネル側を「受付経路」へ変更 |
| 提供開始 | ローンチ / リリース | リリース側を「提供」へ変更 |

変更後は、複数項目で完全一致する日本語案が0件になった。意味が近い項目は統合せず、
合う場面、理由、例文で境界を明示した。詳細は
[`DUPLICATE_REVIEW.md`](./DUPLICATE_REVIEW.md) にまとめた。

### 3. 表現を再確認する候補

全案を一覧で確認し、特に次の6候補を例文と利用場面を含めて再確認した。

- アイスブレイク: 「場ほぐし」から「場を和ませる導入」へ変更
- インフルエンサー: 「有力発信者」から「人を動かす発信者」へ変更
- マネタイズ: 「収入化」から「収益につなげる」へ変更
- オブザーバビリティ: 「状態把握性」から「状態の調べやすさ」へ変更
- アルゴリズム: 「算法」から「計算手順」へ変更
- クラウド: 「外部基盤」から「ネット経由の計算環境」へ変更

専門用語として正確な案は第1案に残し、第2案を専門外にも意味を説明できる自然な表現へ
整理した。

### 4. 分類の偏り

初期データで使われている分野は6つで、「教育」「日常」は0件だった。
タグは8つすべて使用されている。

[`CLASSIFICATION_RULES.md`](./CLASSIFICATION_RULES.md) で、使われ方ごとに主な分野を
1つ選び、タグを原則1〜3個付ける基準を定めた。「教育」「日常」は既存6分野では
表しにくい独立した利用場面として残す。件数を埋めるための投稿は作らず、
該当する実例が集まったときに使用する。
